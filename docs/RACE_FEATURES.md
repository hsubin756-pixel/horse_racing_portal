# 확장 기능 사용 안내

## 화면과 데이터
기본 제공 자료는 모두 합성 샘플입니다. 실제 JRA/NAR·넷케이바 API, 실시간 배당 또는 외부 알림 발송을 연결하지 않았습니다. 관리자 등록 자료는 입력한 출처를 표시하며 자동으로 진위를 검증하지 않습니다.

| 기능 | 사용 위치 | 현재 범위 |
|---|---|---|
| 출마표 상세 | 경주 상세 | 발주 시각, 등급, 날씨, 주로 상태, 게이트, 부담중량, 마체중/증감, 출전/경주 상태 |
| 구간 기록·주행 스타일 | 말 상세 / 경주 상세 | 거리별 통과 순위·누적 시간·구간 시간, 마지막 600m, 최근 스타일 분포 |
| 관리자·CSV | `/admin` | 말·경주·출전·구간·배당/환급·인물 등록/수정, 미리보기, 일괄 저장, 변경 이력 |
| 배당·환급표 | 경주 상세 | 단승/연승/복승/쌍승/삼복승/삼쌍승, 예상 배수/확정 환급/환불 구분 |
| 개최 캘린더 | `/calendar` | 월별 달력, 경마장 이름 필터, 발주 시각·상태, 경주 상세 링크 |
| 개인 메모·태그 | `/notes` 및 말/경주 상세 | 회원별 비공개 메모·태그, 문자 검색, 수정/삭제, 수정 충돌 검사 |
| 기수·조교사 | `/people` | 고유 ID 프로필, 소개, 연도·경마장별 우승/출전 순위, 최근 전적 |
| 성적 추이 | 말 상세 | 최근 10경주 착순 막대, 경주 선택 시 구간 순위 그래프/표 전환 |
| 사이트 내 알림 | `/notifications` | 알림함 조회/갱신 시 향후 7일 관심 출전 알림 생성, 중복 방지, 읽음 상태 |

기존 이름 기반 기수 통계는 호환성을 위해 유지합니다. 새 인물 프로필은 ID로 구분합니다. **조교사 집계는 현재 등록된 담당 말의 전적 기준**이며, 과거 조교사 변경 당시의 소속 이력은 아직 없습니다. 수득상금·말/기수 조합 통계는 이번 구현 범위에 포함하지 않습니다.

## 구간 기록과 스타일의 해석
`sectional` 한 행은 개별 말의 **출발부터 거리(m)**, 그 지점의 통과 순위, 누적 시간(초), 출처입니다. 순위 또는 시간만 제공할 수도 있습니다. 거리/시각이 없는 코너 위치를 임의 거리로 바꾸지 않습니다. 개별 말의 누적 시간에서 앞 지점 누적 시간을 빼서 구간 시간을 표시하며, 선두가 바뀔 수 있는 **경주 전체 랩 타임과 구분**합니다.

- 첫 지점은 출발부터의 시간입니다. 중간 시각이 누락되면 해당 구간 시간을 추정하지 않습니다.
- 마지막 600m는 정확히 `전체 거리-600m`와 결승 지점의 누적 시간이 모두 있을 때만 계산합니다.
- 최근 확정 완료 10경주에서 초반(600m 이내이면서 전체 거리 절반 이내) 첫 유효 순위를 사용합니다. 취소마는 출전 두수에서 제외합니다.
- 초반 1위는 **선행**, 상위 1/3(올림) 이내는 **선입**, 다음 1/3은 **중단**, 나머지는 **추입**으로 분류합니다. 후미 출발을 추입 경향이라고 부르는 규칙이며 막판 가속/추월 성공을 증명하지 않습니다.
- 유효 전적이 3개 미만이면 **판단 보류**, 3개 이상에서 한 유형이 60% 이상이면 그 유형, 나머지는 **혼합형**입니다. 분포와 표본 수를 함께 표시합니다.
- 공식 각질 판정, 학습된 분류 모델, 실제 능력/승률 예측이 아닙니다. 추이 막대도 서로 다른 거리·상대·주로의 능력을 보정한 지수가 아닙니다.

기본 7개 완료 경주의 11두에 4개 지점씩, 총 **308개**의 가상 구간을 추가했습니다. 33번 말은 구간 누락 예시입니다. 가상 순위/시간은 실제 경마에서 가져오지 않았습니다.

## 경주와 출전 상태
경주: `SCHEDULED` 예정, `RUNNING` 진행/심의, `OFFICIAL` 결과 확정, `CANCELLED` 취소.
출전: `DECLARED` 예정, `FINISHED` 완주, `SCRATCHED` 출전 취소, `DNF` 중지, `DISQUALIFIED` 실격.

관리자가 상태를 기록하며 발주 시각만으로 결과 확정 상태로 자동 변경하지 않습니다. 통계·과거 전적·모델 과거 입력은 확정 경주의 완주 착순만 사용합니다. 일정은 예정 경주와 출전 예정 말만 포함합니다. 취소 경주는 예측을 거부하며 취소·중지·실격 출전은 예측 대상에서 제외합니다. 현재 진행 중인 경주의 실시간 예측 기능을 뜻하지 않습니다.

## 관리자 설정
1. 사이트에서 관리자로 사용할 계정을 일반 회원으로 가입합니다. 기본 관리자 계정/비밀번호는 생성하지 않습니다.
2. 저장소를 관리하는 WSL 터미널에서 실행합니다. `실제가입이메일`을 본인의 가입 이메일로 바꾸세요.

```bash
cd ~/projects/horse_racing_portal_wsl
python3 scripts/admin.py 실제가입이메일
```

3. 해당 계정으로 로그인하고 상단 **자료 관리**를 엽니다. 일반 회원은 API에서도 403으로 거부합니다.
4. 권한 회수: `python3 scripts/admin.py 실제가입이메일 --revoke`. DB의 권한을 요청마다 확인하므로 기존 로그인도 다음 관리자 요청부터 거부됩니다.

이 명령은 로컬 Docker DB 관리 권한을 가진 저장소 운영자용입니다. 웹 회원가입으로 관리자 권한을 지정할 수 없습니다.

## 등록·정정과 CSV
자료 종류를 고른 뒤 양식을 작성하거나 CSV를 올립니다. 화면에 종류별 CSV 열 이름을 표시합니다. UTF-8, 첫 행 헤더, 쉼표 구분, 따옴표로 감싼 쉼표/줄바꿈/쌍따옴표를 지원합니다. 1회 최대 100행/200KB이며 알 수 없는 열·중복 헤더·잘못된 숫자/참조를 거부합니다.

- 새 자료는 `id`, `revision`을 비웁니다. 수정은 목록에서 불러온 두 값을 유지합니다.
- 말·인물·경주를 먼저 등록한 뒤 해당 ID로 출전 → 구간/환급 자료를 연결합니다. 기수/조교사 ID를 연결하면 해당 인물 이름을 사용합니다. 이름만 입력한 자료는 인물별 집계에 연결되지 않습니다.
- 미리보기는 **형식·참조 검사**이며 DB에 저장하지 않습니다. 미리보기 결과를 **저장 대기 목록**에 담고 **전체 변경 저장**을 누릅니다.
- 저장 시 전체 정합성을 다시 검사합니다. 서로 연관된 경주 상태·출전 결과·배당을 여러 묶음으로 담아 한 transaction에 저장할 수 있습니다. 어느 하나라도 실패하면 자료와 변경 이력 모두 취소합니다.
- 예: 예정 경주의 결과를 등록하려면 경주 상태 변경과 출전 착순을 같은 저장 대기에 담습니다. 기존 예상 배당이 있으면 같은 배당 행을 확정/환불로 함께 정정합니다.
- 다른 관리자가 먼저 수정하면 409로 거부합니다. 자료를 다시 불러온 뒤 변경을 적용합니다. 저장 대기 내용은 화면 메모리에 있으므로 새로고침 전 저장해야 합니다.
- 구간 누적 시간 증가, 거리/순위 범위, 결승 시간·순위와 일치, 취소마 기록, 혈통 순환을 검사합니다. 잘못된 구간/배당 자료는 목록에서 삭제할 수 있으며 이력에 남습니다. 말·경주·출전·인물은 삭제하지 않고 정정과 취소 상태로 관리합니다.
- 최근 100개의 변경 이력을 관리자 화면에서 조회하며 DB에는 변경 전후 값·담당 회원 ID·시각을 저장합니다. 인물 이름 변경은 연결된 이름 표시에도 반영됩니다.

예시 인물 CSV:

```csv
id,revision,kind,name,biography,source
,,JOCKEY,가상 새 기수,"가상 소개, 등록 예시",synthetic_sample
```

예시 구간 CSV(실제 존재하는 출전 ID로 바꾸어야 합니다):

```csv
id,revision,entry_id,distance,position,cumulative_seconds,source
,,1,600,1,36.20,synthetic_sample
```

기존 거리 지점을 정정할 때는 새 행을 만들지 말고 기존 구간 ID/버전으로 수정합니다. 시각은 `2026-10-23T03:00:00Z`처럼 UTC 오프셋을 포함한 ISO 형식으로 입력합니다.

## 환급표의 단위와 검사
예상 배당은 배수, 확정 환급/환불은 **100엔당 원금을 포함한 엔 금액**입니다. 무순서 조합(복승·삼복승)은 마번을 오름차순 정규화하고 순서 조합은 순서를 유지합니다. 같은 경주/승식/조합을 중복 등록할 수 없습니다. 확정 환급은 확정 경주의 적중 착순과 대조하며 동착의 동일 순위 조합을 허용합니다. 연승은 이 구현에서 8두 이상 3위 이내, 그 미만 2위 이내 규칙을 사용합니다. 공급원별 판매 조건·특수 환급 규칙은 아직 모델링하지 않았습니다.

환불은 경주 취소 또는 조합 내 취소마가 있을 때 100엔으로 기록합니다. 금액은 등록된 값을 표시하며 투표 총액으로 배당을 계산하거나 베팅·결제를 처리하지 않습니다.

## 알림의 동작 범위
알림함을 열거나 **알림 갱신**을 누를 때 관심 경주/관심 말의 7일 내 예정 출전을 확인합니다. 회원·경주·개최일별 1건만 생성하고 읽음 상태는 갱신해도 유지합니다. 기존 알림은 관심 해제 후에도 남으며 경주의 현재 상태를 함께 보여줍니다. 최근 100건을 표시합니다. 사이트를 닫아 둔 동안 실행하는 스케줄러, 이메일·웹푸시·문자 발송은 포함하지 않습니다.
