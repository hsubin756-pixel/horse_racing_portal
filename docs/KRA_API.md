# 한국마사회 경주성적 API 연결 확인

API214_1 개발계정 승인 후 사용하는 **로컬 연결 확인·원본 다운로드 도구**입니다. Python 표준 라이브러리만 사용하므로 Docker 실행, npm 설치, Python 추가 패키지가 필요하지 않습니다. API 호출은 사용자의 PC에서 이루어집니다.

현재 단계는 인증과 원본 응답을 확인하는 단계입니다. 다운로드한 자료를 사이트 DB에 반영하거나 실제 데이터로 ML을 학습하지 않습니다. 사이트의 기존 합성 자료는 그대로 표시됩니다.

## 처음 한 번 설정

WSL Ubuntu 터미널에서:

```bash
cd ~/projects/horse_racing_portal_wsl
git pull --ff-only
python3 scripts/kra.py configure
```

공공데이터포털의 **마이페이지 → 데이터 활용 → Open API → 개발계정 → 한국마사회_경주성적정보**에서 인증키를 확인합니다. 메뉴 이름은 포털 개편에 따라 다를 수 있습니다. 해당 API의 승인 여부를 확인하세요.

가능하면 **일반 인증키(Decoding)**를 복사하고, 위 명령이 입력을 기다릴 때 터미널에 붙여넣어 Enter를 누릅니다. 입력한 문자가 화면에 보이지 않는 것이 정상입니다. Encoding 키도 한 번 디코딩해서 처리합니다. URL 전체를 붙여넣지 마세요.

키는 Git에서 제외된 `.runtime/kra/service-key`에 소유자만 읽고 쓸 수 있는 권한으로 저장됩니다. 암호화 저장은 아닙니다. 채팅·스크린샷·GitHub에 키를 공유하지 마세요. 다시 `configure`를 실행하면 키를 바꿀 수 있습니다. 기존 `.env`와 Docker 설정을 수정할 필요가 없습니다.

자동화 환경에서는 `KRA_SERVICE_KEY` 환경변수를 사용할 수 있으며 이 경우 저장 파일보다 우선합니다. 명령행 인수로 키를 받지 않습니다.

## 연결 확인 (한 번 호출)

```bash
python3 scripts/kra.py check --meet 1 --date 20220220 --race 1
```

문서에 수록된 **서울 2022년 2월 20일 1경주** 조건입니다. 현재 API가 그 기간의 자료를 제공하는지는 실제 호출로 확인해야 합니다. 이 도구는 `rc_date`만 지정하며, 원본 가이드 예제의 중복 연도·월 조건을 복사하지 않습니다.

성공 예시(건수는 실제 응답에 따라 달라집니다):

```text
API 연결 성공: 전체 N건 / 수신 N건 / 호출 1회
전체 조회 완료
저장 위치: .runtime/kra/results-...
```

`check`는 첫 100건만 확인합니다. 더 많은 건수가 있으면 **첫 페이지 확인 완료**라고 표시하고 `summary.json`에 `complete: false`를 기록합니다. 0건은 인증 실패와 다릅니다. 해당 경주일·경마장·제공 기간을 확인하세요.

오류는 키나 요청 URL 없이 표시합니다. 오류 20/30은 승인 내역 및 키, 31은 사용 기간, 32는 허용 IP, 22는 호출 한도를 확인하세요. HTTP/네트워크 오류만으로 인증 실패라고 판단하지 않습니다. 실패 시 자동 반복 호출하지 않습니다.

## 해당 날짜 전체 내려받기

연결이 확인된 뒤 필요한 날짜로 바꿔 실행합니다:

```bash
python3 scripts/kra.py fetch --meet 1 --date 20220220
```

- `--meet`: 1 서울 / 2 제주 / 3 부산경남. 영천은 문서 간 버전 차이가 있어 아직 선택지에 추가하지 않았습니다.
- `--date`: YYYYMMDD 형식. 초기에는 하루만 조회하세요.
- `--race`: 특정 경주만 받을 때 추가합니다.
- 한 페이지 100건, 실행당 최대 10페이지(10회 호출), 페이지 사이 최소 0.25초 대기. 한도를 넘으면 `--race`로 범위를 줄이세요. 이 상한은 개발 도구의 자체 제한입니다.
- 각 실행은 새 디렉터리에 XML 원본 페이지와 `summary.json`을 저장합니다. 인증키가 응답에 그대로 포함돼 돌아오면 해당 문자열을 제거합니다. 오류 응답은 저장하지 않습니다.
- 전체 건수 변경·불완전 페이지·동일 말의 동일 경주 중복·조회 날짜 불일치를 감지하면 정상 완료로 처리하지 않습니다. 시점별 정정 여부와 모든 필드의 의미까지 검증하는 도구는 아닙니다.

## 제공 조건과 연동 시 주의점

사용자가 2026-10-23 제공한 [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15063979/openapi.do) PDF에는 무료, 이용허락범위 제한 없음, 개발 자동승인/운영 심의승인, 개발 트래픽 3,000이 표시돼 있습니다. PDF에는 호출 한도의 집계 기간이 없으므로 포털 계정의 실제 한도를 확인하세요. 공개 운영 시 운영계정 조건을 확인해야 합니다.

`API214_1_한국마사회 경주성적정보.docx`와 위 PDF를 근거로 작성했습니다. 최신 PDF는 HTTPS·JSON/XML·영천을 안내하지만 가이드의 개요는 HTTP·XML·3개 경마장을 안내합니다. 이 도구는 HTTPS와 XML을 사용하고 실제 호출 성공은 별도로 검증해야 합니다.

- `hrNo`, `jkNo`, `trNo`는 선행 0을 보존하는 문자열입니다. `chulNo`는 출전번호이며 말의 고유번호와 다릅니다.
- 서울: 누적 시간. 제주: 구간 기록. 부산경남: 구간 및 누적 시간. 원본 필드를 보존하며 현재 도구는 임의로 시간을 변환하지 않습니다.
- 사용하지 않는 구간에 0이 나타납니다. 이를 실제 0초/0위로 해석하지 않습니다. 모든 필드의 0이 결측이라는 뜻은 아닙니다.
- S1F는 출발 200m, G3F/G1F는 결승 전 600m/200m입니다. 코너는 근거 없이 거리 좌표로 변환하지 않습니다.
- `winOdds`는 단승 배당입니다. `plcOdds`는 포털의 연승 설명과 DOCX의 복승 설명이 충돌하므로 의미 확인 전 승식을 확정하지 않습니다.
- 공식 인기 순위·예정 출전표·실시간 배당 추이는 이번 명세에서 확인되지 않았습니다. `rankRise`(승군순위)를 인기 순위로 사용하지 않습니다.
- 한국 자료를 현재 사이트에 넣기 전 제공기관 ID 매핑, 구간 자료 구조, 통화, 경주별 조교사 이력, 취소/실격 및 결과 확정 처리 등을 검증해야 합니다.
