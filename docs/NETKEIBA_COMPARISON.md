# 넷케이바와의 기능 범위 비교 초안

기준일: 2026-10-23 (한국 시간). 대상: https://www.netkeiba.com/

## 확인 범위와 제한
이 환경에서 홈페이지, https://race.netkeiba.com/top/ 및 https://db.netkeiba.com/ 에 공개 페이지 읽기를 시도했으나 네트워크 프록시에서 `403 Forbidden`으로 차단됐습니다. 따라서 **넷케이바 최신 화면·전체 메뉴·유료 회원 영역을 직접 확인한 비교가 아닙니다.** 아래는 넷케이바의 알려진 주요 서비스 영역을 비교 기준으로 삼아, 우리 저장소와 실제 실행 결과에서 확인한 구현 여부를 정리한 것입니다. 현행 메뉴 이름·유료/무료 구분·누락 기능의 완전성은 미확인입니다. 넷케이바의 콘텐츠나 데이터를 복제하지 않았습니다.

표의 ‘구현’은 포털의 가상 데이터에서 동작한다는 뜻입니다. 실제 일본 경마 데이터 공급원은 연결되어 있지 않습니다.

## 다음 구현 우선순위
1. **경주 정보 보강:** 발주 시각·등급·부담중량·마체중·출전 상태·주로 상태와 확정 환급표. 현재 가상 데이터로 화면과 입력 계약을 설계할 수 있습니다.
2. **관리자 데이터 관리:** 말·경주·출전 정보 편집, CSV 검증/미리보기/적재, 출처와 변경 이력. 실제 데이터 도입 전에도 운영성을 개선합니다.
3. **실제 자료 연동:** 사용·저장·재표시가 허용되는 공급원 계약과 API 스키마를 확보한 뒤 중앙/지방 경마 식별자·갱신 주기·결과 확정 상태를 연결합니다. 현재 사용자가 허가된 데이터를 보유하지 않았으므로 이 단계는 미진행입니다.
4. **알림·콘텐츠·커뮤니티:** 공개 서버, 운영 정책, 콘텐츠 공급 조건에 따라 별도 진행합니다.

현재 요청으로 구현한 범위는 말 비교, 말·기수 조건별 성적, 관심 경주 저장과 관심 말 출전 일정입니다. 위 미구현 항목 전체를 구현했다고 주장하지 않습니다. 최신 넷케이바 화면을 직접 열 수 있는 환경에서 메뉴별 재확인이 필요합니다.
