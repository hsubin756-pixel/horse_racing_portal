이 문서는 기능 코드 기준 `main`의 `4cc91ec`까지를 살펴본 기록입니다. 이전 작업 기록은 [PROGRESS.md](../PROGRESS.md), 검증 과정은 [TEST_REPORT.md](../TEST_REPORT.md)에 있습니다. 아래에서 **코드에 포함된 기능**, **이전 작업 환경에서 보고된 실행 결과**, **이번 클라우드 작업 공간에서 직접 확인한 결과**를 구분합니다. 현재 사용 중인 PC는 이전 작업 환경과 별개이며, 그 PC의 DB 상태는 확인하지 않았습니다.

## 최근 추가한 개선

[최근 전적 수집·경마장별 평가·구간 비교](KRA_SYNC.md)에 실행 절차를 정리했습니다. `kra_sync.py`가 최근 3개월 사이트 전적/학습 자료 수집과 재개·실패 기록·진행표를 제공하고, `evaluate_tracks.py`가 서울 단독/서울+부산/제주 별도 평가를 수행합니다. 경주 상세에 최대 4두 구간 비교와 공통 배당 출처 표시를 추가했습니다. **사용자 PC 출력 기준 학습 수집 276/276, 사이트 완료 223/276, 실패·보류 53개 날짜×경마장입니다.** 141개 보류 경주의 최초 오류는 착순 138개·기수 번호 2개·거리 1개이며, 저장 원본의 실제 값을 확인하기 위한 진단을 추가했습니다. 통합 모델 서울/부산 AUC 0.660/0.759, 제주 모델 0.651로 각각 시장 기준선보다 낮았고 서울 단독은 날짜 부족으로 미평가입니다. 서비스 모델은 교체하지 않았습니다. 실제 CSV·원본·DB는 이 클라우드에서 직접 확인하지 않았습니다. 아래는 이전 단계별 상태 기록입니다.

### 비완주 원본 진단 후 개선
사용자 후속 진단에서 83개 경주의 표시 표본에 92/주행중지·94/경주제외·95/출전취소가 확인됐습니다. 해당 코드/비고 쌍을 지원하고 출주표 상태·원래 비고를 보존하며, 착순·시간은 NULL로 저장합니다. V11 마이그레이션이 필요하므로 서비스 재빌드 후 API 호출 없는 `--max-calls 0 --apply --retry-failed`로 재처리합니다. 남은 진단 분류는 ord=0인 54경주, 거리 공란 1경주, 경주불성립 1경주, 미확인 기수 번호 2경주입니다. 실제 재처리 성공 수는 사용자 실행 확인 전입니다. 완주마의 다른 필드 오류가 추가로 드러날 수 있습니다.

기능 코드 `b760b7f`(패치 0018~0020)를 반영하고 클라우드에서 최신 Compose를 재빌드·기동했습니다. 아래 10월 23일 검증 기록 이후 V10과 실데이터 모델의 기동, 예측 브라우저 5개, DB 통합 6개, ML 9개와 갱신/변환 오프라인 19개 검사를 직접 확인했습니다. DB 검사는 제공기관 형식의 가상 자료를 사용했으며 현재 사용자의 PC 상태와는 별개입니다.

최신 근거와 수정 내용은 [TEST_REPORT.md](../TEST_REPORT.md)의 2026-10-26 후속 실행 검증, 사용자 환경의 후속 명령은 [KRA_API.md](KRA_API.md)와 [ML_DATA.md](ML_DATA.md)를 참고하세요. 아래는 10월 23일 기준 기능과 이전 환경 기록입니다.

- **이번 작업 공간에서 직접 확인:** GitHub `main` 4cc91ec까지 가져왔고, Gradle `test` 성공, 프런트엔드 production build 성공, ML Python 단위 테스트 8개 통과. 커밋된 CSV를 파싱해 10,555행·1,018경주·97개 경주일(2025-01-04~12-28)을 확인했습니다. 이 작업 공간의 실행 중인 DB와 이미지는 새 커밋으로 재기동하지 않았으므로 V10/실제 웹 흐름을 이번에 다시 검증한 결과로 취급하지 않습니다.
- **이전 작업 환경에서 보고되어 저장소에 기록:** 실제 서울 경주 1건·14두(2022-02-20), 말 프로필 14두, 기수 469명·조교사 42명, 향후 예정 경주 21건 반영. V10 적용, Gradle 빌드, 관련 API/브라우저 검사, 실제 모델 화면 확인 기록이 있습니다. 이 수치는 이전 환경의 DB에 대한 보고이며 현재 PC나 이번 클라우드 작업 공간에서 그 DB를 직접 조회한 결과가 아닙니다.
- **모델의 과거 홀드아웃 기록:** 시장 정보 없는 확장 모델 ROC-AUC 0.738, AP 0.497, 경주별 상위 3두 recall 0.526. 2025년 서울 자료의 **한 번의 시간순 분할** 결과이며 미래 성능·승률·수익률을 보증하지 않습니다. 서비스 모델은 전체 학습 자료로 다시 학습합니다. [평가 방식과 비교](ML_DATA.md)를 참고하세요.

## 현재 제한과 다음 우선순위

1. 한국마사회 API 자료는 운영자가 로컬에서 수집·미리보기·반영합니다. 자동 갱신·정정 처리·취소/중지/실격 경주의 전체 반영, 다른 경마장 결과는 아직 완성되지 않았습니다. 배당이 없는 말은 배당 기준 인기를 매기지 않으며, 공식 인기 순위로 표시하지 않습니다.
2. 예측 모델의 학습 이력은 **2025-12-28**에 고정됩니다. 2022년 경주에서 모델 화면이 동작한다는 사실은 당시 시점의 사전 예측 검증이 아닙니다. 학습 시점 이후 데이터의 시간순 재평가·정기 갱신, 다른 연도/경마장 평가, 점수 보정이 다음 모델 과제입니다.
3. 공개 서버·도메인·실제 HTTPS 배포는 없습니다. 현재는 본인 PC의 WSL/Docker에서 확인하는 개발/시연 환경입니다. 공개 운영 시 공공데이터포털 **운영계정 심의**, 개인정보/계정 복구, 외부 백업·복원과 장애 감시가 필요합니다. 서버를 지금 구매할 필요는 없습니다.
4. 사이트 내 알림은 화면을 열거나 갱신할 때 생성됩니다. 이메일/푸시 발송과 커뮤니티·베팅 기능은 없습니다. 넷케이바 최신 화면과의 직접 비교는 외부 접속 403으로 검증되지 않았습니다.

이 문서는 코드를 통한 기능 확인과 실행 기록의 범위를 설명합니다. 실제 제공기관 응답의 항목·사용 조건은 [공공데이터포털 안내](https://www.data.go.kr/data/15063979/openapi.do) 및 계정별 승인 내역을 최종 기준으로 확인해야 합니다.
